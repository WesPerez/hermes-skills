## 关键发现

| 发现 | 影响 |
|------|------|
| **Enter 重置页面** | 图像生成模式下按 Enter 导致输入框清空回到首页。**必须点击发送按钮** |
| **比例在提示词前设置** | 比例按钮要在输入提示词之前设置，否则不生效 |
| **封面图比例** | "比例"菜单中"3:4"的显示文本是"3:4 经典比例，拍照" |
| **COLG 搜索路径** | `https://bbs.colg.cn/` → 搜索"魔道学者 表情包" → 找到相关帖子 |
| **Referer 防盗链** | 加 `Referer: https://www.doubao.com/` 即可正常下载，防盗链不严格 |
| **URL 格式** | `https://p5-flow-imagex-sign.byteimg.com/tos-cn-i-a9rns2rl98/rc_gen_image/<hash>.jpeg~tplv-a9rns2rl98-downsize_watermark_1_5_b.png?<params>` |
| **模型** | 默认使用 Seedream 4.5（不需要切换） |
| **角色名兼容** | 豆包对 DNF 角色名（魔道学者、井盖）无敏感词限制 |
| **登录状态** | 右上角显示用户头像和昵称（如"Wes"）表示已登录 |
| **每批数量** | 每次固定生成 4 张图 |
| **风格/模板按钮** | 可用但非必须，默认 Seedream 4.5 出图质量已经不错 |
