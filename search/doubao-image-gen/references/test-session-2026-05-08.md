## 关键发现

### 1. 比例菜单选项（2026-05-08 版）
```
1:1 正方形，头像
2:3 社交媒体，自拍
3:4 经典比例，拍照      ← 默认推荐
4:3 文章配图，插画
9:16 手机壁纸，人像
16:9 桌面壁纸，风景
```

### 2. 发送方式
- **❌ Enter 键**：会重置页面，回到首页
- **✅ 点击发送按钮**：箭头图标，在输入框右侧

### 3. 防盗链
- 加 `Referer: https://www.doubao.com/` 即可 curl 下载
- 不需要 cookie 或其他特殊处理

  - 「肥鯮与魔界人表情包渊源」— 描述了魔道学者（井盖）作为 DNF 表情包顶流的地位
  - 经典外观：雪人套 + 像素头
  - 社区昵称：井盖
